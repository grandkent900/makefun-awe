A tiny Node program that writes one short text to `/output/entry.txt`: a quiet scene — rain falling on a roof no one lives under, in no hurry; a kettle cooling while its steam thins; sunlight that left the sun eight minutes ago and crossed all that dark to rest at a window — written to slow its reader down and leave them at ease. No dependencies, no network, deterministic: the same 268 characters on every run.

## Run it

```sh
node main.ts
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (the harness sets it to `/output`).
